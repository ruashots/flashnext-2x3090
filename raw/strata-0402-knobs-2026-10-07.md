# Tuning on Strata v0.1.40.2, 2026-10-07: what was tried and why it was or was not kept

One knob at a time against the same live baseline (label `live-0.1.40.2-262k`), this repo's harness, plus the engine's own timing.
Rows: `strata-0402-bench-2026-10-07.jsonl`, `strata-0402-quality*-2026-10-07.jsonl`, `strata-0402-vision-2026-10-07.jsonl`.

## Kept

**Image cap 4096 tokens (was 1024).** Test: a 2560x1440 screenshot of a log in small type with 7 error codes.
1024: 0 of 7 exact (1,055 tokens). 2048: 0 of 7, each one letter off (2,027 tokens). 4096: 6 of 7 exact, the 7th one letter off (3,647 tokens), about 8 s per new screenshot when warm.
Cost: the image encoder takes 1.8 GB of VRAM instead of 1.33 GB, so the first card holds 7,130 expert slots instead of 7,315 (1.3% fewer of 14,630). No text-speed loss beyond noise. Image during a running answer and two-at-once (100-110 tok/s together) pass. Small photos are unchanged; the cap is a maximum.

## Not kept

**reasoning_loop_recovery "recover".** With thinking on, the 20-prompt set triggered it on 3 of 20 normal questions (code-2, code-4, code-5: long code designs where the model re-drafts code). Reading the thinking, it was real progress, not a loop. When it fires it switches the effort to low and raises temperature and presence penalty mid-answer. "stop" would cut those answers off instead. Thinking-off quality unchanged (5/6). No attempt was made to provoke a real loop: the false-trigger rate on normal work decided it.

**Coupled Gumbel drafts (STRATA_SPEC_COUPLED=1, STRATA_SPEC_GUMBEL=1).** 69% of drafts accepted against 72% without it; engine decode 87 against 90 tok/s; harness slightly lower. No gain, matching the RTX 3060 result in Strata's docs.

**--spec-min-p 0.7 (was 0.5).** 82% of drafts accepted instead of 71%, but fewer tokens per step; engine decode 94 against 87-91 tok/s on the other runs, harness up on some cells and down on others. Within noise, so the default stays.

## Not tested, with reasons

- STRATA_PREFILL_CPU_SHARE: the engine enables it only on one GPU without batching, so it does nothing on this two-card, two-at-once setup.
- --expert-cache-per-layer: it ignores the expert profile's ranking, which this setup relies on.
- STRATA_IO_PREFETCH: Strata's docs measure no gain once the experts are warm in the page cache.
- --pipeline-windows: the engine turns it off whenever two-at-once batching is on.
- --batch-mtp: open crash bug upstream (#1121) at the time.

Other clients of the server (agents) sent requests during these runs; expect some noise in every row.
