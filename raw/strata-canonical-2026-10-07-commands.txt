Canonical benchmark set, Strata 0.1.40.2 on 2x RTX 3090, 2026-10-07. Exact commands, in the order they ran.
Hardware, software versions and the three server configs: strata-canonical-2026-10-07-env.txt (same folder).

Server: Strata v0.1.40.2 (commit e8ca9af), engine built from source with CUDA 13.0 for sm_86, run as
  python -m serve.server --engine strata --config <config> --host 0.0.0.0 --port 8080
Model: Qwen3.8-Flash-Next-OrcaRouter, IQ4_XS GGUF (3 shards) + native pack + MTP draft layer (see env file).
Configs (full JSON in the env file):
  C262 = strata-orca-0402-262k-img4096.json: 262,144 context, 2 requests at once (--batch 2 --batch-groups 2),
         --layer-split 26 --trim-stage-weights, --kv int8 --kv-resident 20480, --mmap-experts, --spec 4 --spec-min-p 0.5,
         conversation parking 8 GiB / 8 slots, images on (4096-token cap).
  C512 = strata-orca-512k.json: 524,288 context, yarn x2, one request at a time, layer split auto.
  C1M  = strata-orca-1m.json:  1,048,576 context, yarn x4, one request at a time, layer split auto.
Client scripts: this repository's scripts/ (bench.py, probe.py, quality.py, autograde.py, gsm8k.py,
needle_multikey.py, needle_stream.py, canonical_*.sh). Haystack for the needle tests: a plain clone of Strata at
tag v0.1.40.2 (git clone https://github.com/Niko1221/Strata && git checkout v0.1.40.2), passed as STRATA=<path>;
its tools/needle_bench.py builds the text from the repo's docs and sources.

U=http://<server>:8080   M=Qwen3.8-Flash-Next-OrcaRouter
